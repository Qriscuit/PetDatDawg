# Steam store artwork

Original marketing PNGs from the shared [Pet Da Dog asset folder](https://drive.google.com/drive/folders/1FuRSUheNvpy9rXZlQkTX8Rh3XpYCGfUV), synchronized October 28, 2026.

`Art/` contains the small, header, library and vertical capsules, main capsule, library hero and text logo. These are source artwork for Steamworks, kept outside the Godot client so unused marketing images do not enter the game package. Adding them here does not upload or publish a Steam store page.

See [the asset audit](../docs/ASSET_AUDIT.md) and [source manifest](../docs/asset-source-manifest.json) for the Drive file IDs, canonical paths and SHA-256 hashes.
